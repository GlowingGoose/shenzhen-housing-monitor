# 中国各大城市历史房价走势

国家统计局 70 城房价指数与中指研究院城市挂牌房价、挂牌租金的交集看板：[在线查看](https://glowinggoose.github.io/shenzhen-housing-monitor/)。

## 内容

- 只展示三套名单的交集；当前 42 城，其他 28 城不进入筛选、图表或租售比。
- 租售比、环比走势、同比走势分为三个页签；城市多选、城市等级快捷选择同步作用于三个页签。
- 环比和同比页签均可筛选新房/二手房、月份范围，并在热力图和折线图之间切换。
- 租售比按同月二手挂牌均价与住宅挂牌月租金计算，展示为 `1:N`；可切换历史月份，并查看原始价格与来源链接。
- 两类数据分别显示最新月份与检查状态；抓取失败时保留上一份有效数据，显示警告并使工作流失败。

页面采用深绿与暖白配色，参考[绿城中国公开品牌资料](https://www.greentownchina.com/tc/ir/presentations/pre240325.pdf)的绿色视觉语言；红涨、蓝跌的图表语义保持独立。本站与房企没有隶属关系。

## 自动更新

GitHub Actions 每天按 UTC 02:23 计划检查国家统计局和中指研究院两个来源，也可手动运行；计划任务可能延迟。统计局发布新月报后增加指数月份；中指研究院的房价和租金同月齐备后更新租售比。不同月份的租金和房价不会拼接。异常可在 Actions 页查看。

无需外部服务器或 API 密钥；工作流使用仓库自带的短期 `GITHUB_TOKEN`。若中指来源仍停在上上个月且已到本月 15 日，或可比城市名单变化，会保留已核验数据并报错待核对。

## 数据与口径

国家统计局原始库从 2023 年 1 月起覆盖 70 城的新房与二手房环比、同比指数；对外看板只显示与中指 50 城租金、百城二手房价名单相交的城市。租售比历史从 2026 年 9 月开始逐月积累，不反推更早的挂牌价。名单变化会触发校验。相同城市名称不保证不同机构的样本范围完全一致；两种数据分别展示。

**租售比 = 单位面积月租金 : 单位面积二手房价 = 1 :（房价 ÷ 月租金）。**例如房价 50,000 元/㎡、月租金 100 元/㎡/月，租售比为 `1:500`。它可换算为年化毛租金回报率，但看板只展示月度租售比，避免混称。定义参考[诸葛找房报告（中国房地产业协会转载）](https://www.fangchan.com/data/13/2020-12-21/6746692391039996794.html)。数据来源：[中指租金](https://www.cih-index.com/data/index/rentIndex.html)、[中指二手房价](https://www.cih-index.com/data/index/esfHouse.html)。

中指租金和房价是城市挂牌样本，未逐套配对；`1:N` 不是某套房实际回收期，也未考虑空置、税费、维修及交易成本。国家统计局城市指数不代表某个小区。具体交易还需结合真实成交、库存、通勤与个人可负担性。商业数据自动获取依赖网页结构；页面变化时程序保留旧数据并报错。

统计局发布页：https://www.stats.gov.cn/sj/zxfb/
