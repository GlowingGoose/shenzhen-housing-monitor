# 住宅价格与租售比观察

国家统计局70城价格指数与中指研究院城市挂牌价、挂牌租金的交集看板，部署于 GitHub Pages。

## 内容

- 全景热力图只展示三套名单的交集；当前为42城，另外28城不进入选择栏、图表或租售比指标。
- 支持城市多选、城市等级快捷选择、住宅类型、环比/同比及月份范围筛选。
- 可切换折线图比较所选城市；点击数据查看环比、同比和官方原文。
- 每城显示同月二手挂牌均价、住宅挂牌月租金、税前毛租金回报率和房价/年租；保留数据来源。
- 两类数据分别显示最新月份与检查状态；任一抓取失败保留上一份数据、标示异常并使工作流失败。

## 自动更新

GitHub Actions 每天按 UTC 02:23 计划检查国家统计局和中指研究院两个来源，支持手动运行；计划任务可能延迟，不能视为精确执行时间。国家统计局发布新月报后增加价格指数月份；中指研究院的房价和租金同月齐备后更新租售比。两种来源互不补月，也不把不同月份的租金和房价拼接。每次检查保存状态，出现异常可在 Actions 页查看。

无需外部服务器或 API 密钥；工作流使用仓库自带的短期 `GITHUB_TOKEN`。若来源仍停在上上个月且已到本月15日，或可比城市名单变化，会保留已核验数据并报错待核对。

## 数据与规则

国家统计局原始库从2023年1月起覆盖70城的新房与二手房环比、同比指数；对外看板只显示与中指50城租金、百城二手房价名单相交的城市。中指的租售比历史从2026年9月开始逐月积累，不反推更早的城市挂牌价。当前严格同名交集是42城；名单变化会触发校验，不能静默混入旧数据。相同城市名称也不保证统计局与中指的样本范围完全一致；两者仅分别展示。

毛租金回报率 = 12 × 中指普通住宅挂牌月租金（元/㎡）÷ 中指二手住宅挂牌均价（元/㎡）× 100%。这一比值不是已实现租金收益，两个样本也未逐套匹配；空置、税费、维修及交易成本未扣除。来源页面：[中指租金](https://www.cih-index.com/data/index/rentIndex.html)、[中指二手房价](https://www.cih-index.com/data/index/esfHouse.html)。商业数据的自动获取依赖网页结构；未来如果页面变化，程序会保留旧数据并显示失败，需要修复或改用授权接口。

国家统计局城市指数不代表宝安某个小区。具体交易还需结合真实成交、库存、通勤、税费及个人可负担性；无法通过该指数确定底部或顶部。

官方网站：https://www.stats.gov.cn/sj/zxfb/
